# Daily Report Prompt

Generate a short morning report for the user's job search.

Include:

- Applications needing follow-up
- Recruiters waiting on a reply
- Upcoming interviews
- New recruiter suggestions
- Companies with no outreach
- Potential networking opportunities

Rules:

- Use only CRM and retrieved memory data.
- Do not invent counts, dates, or statuses.
- Mention missing data plainly.
- Keep the report brief enough to read in email.
